## 1. 什麼是一種資料類型

一種資料類型是某一類「放著就會被自動刪掉」的資料，PathKeep 替使用者留下來。v0.6 有兩種：瀏覽紀錄、Agent 對話。之後還會加更多，每一種都能各自開關（用戶 2026-11-13）。

每種類型有自己的名稱、一句「為什麼要保存」、自己的來源，和一個空間：導航列上的一組頁面加上自己的色相。

|                    | 瀏覽紀錄                           | Agent 對話                                                                                      |
| ------------------ | ---------------------------------- | ----------------------------------------------------------------------------------------------- |
| 切換鈕上的名稱     | 瀏覽紀錄                           | Agent                                                                                           |
| 為什麼要保存       | Chrome 只留 90 天，Safari 預設一年 | Claude Code 預設 30 天清掉舊對話，Codex 會被手動清理                                            |
| 來源               | 見 [archive.md](archive.md) §1     | 這台電腦上找到的工具，從這幾個裡面：Claude Code、Codex、Pi、DeepSeek Harness（用戶 2026-11-13） |
| 空間的頁面         | 首頁、紀錄、洞察、備份             | 洞察、紀錄、專案、備份                                                                          |
| 切換選單上的狀態行 | `{n} 筆 · {m} 個瀏覽器`            | `{n} 段對話 · 只剩 PathKeep 有 {m} 段`                                                          |
| 一筆資料叫         | 照 app 現在的用詞（`{n} 次瀏覽`）  | 對話（`{n} 段對話`）                                                                            |

所有類型放在同一個存檔裡：同一個加密選擇、同一把密碼、同一次解鎖、同一個排程。

還沒做的類型不出現在任何地方：導航列、切換選單、新手引導、設定裡都沒有。切換選單只放空間，不放整個存檔的狀態。

## 2. 開啟、暫停、關閉，和刪除是兩件事

每種類型有三個狀態，在「設定 › 管理資料類型」切換：

| 狀態 | 說明（設定裡照寫）                         | 備份   | 導航列與切換選單 |
| ---- | ------------------------------------------ | ------ | ---------------- |
| 開啟 | 定時備份，導航列裡看得到                   | 照排程 | 有               |
| 暫停 | 不再備份，已存的照樣能看、能搜             | 不備份 | 有               |
| 關閉 | 不再備份，也不在導航列顯示；已存的資料保留 | 不備份 | 沒有             |

每個說明後面接一句 `存檔裡有 {數量}，{大小}。`

規則：

- 三個狀態都不刪任何東西。已存的留在存檔裡，重新開啟就回來。
- 只剩一個開啟的類型時，不能取消它的最後一個來源。已核准但暫時沒接上的資料夾仍算一個來源。搬入存檔後如果這台電腦原先核准的對話資料夾選擇已無法解析，要重新檢視來源才能備份。
- 一種類型開著卻沒有可以備份的來源時（瀏覽紀錄沒選任何瀏覽器設定檔；Agent 對話在這台電腦上沒有核准的資料夾，例如搬入的存檔不帶這台電腦的核准，或每個工具都關了），它的卡片寫出來，按鈕 `選擇瀏覽器` / `選擇來源` 打開它的備份頁，在那裡選；在選好之前，另一種開著的類型不能暫停或關閉，卡片寫 `「{另一種}」開著，但還沒有可以備份的來源，所以在選好它的來源之前，「{名稱}」得一直開著。`
- 直接把整個存檔資料夾搬到另一個安裝時，原電腦的對話擷取授權與關閉決定留在原安裝的範圍內。新安裝可查看已保存的對話，第一次擷取仍需檢視來源並同意。
- 「暫停」只停備份：這個類型的頁面、設定和它自己的背景工作（例如瀏覽紀錄的連結預覽、頁面摘要、搜尋索引）照常。
- 「關閉」的類型什麼背景工作都不做，設定裡也沒有它那一頁。要匯出或清理它已存的資料，先改成「暫停」：看得到、不備份。
- 至少要有一種開著。想關掉最後一種時不切換，通知 `至少要開著一種資料類型`。
- 關閉後通知 `{名稱}已關閉，已存的資料都還在`。
- 打開一個關閉中類型的網址（例如書籤或舊連結），頁面寫：
  - 標題 `「{名稱}」沒有開啟`
  - `PathKeep 目前不保存這類資料。以前存下的內容還在存檔裡，開啟後就能再看到。`
  - 按鈕 `管理資料類型`；Agent 對話另有 `預覽並開啟 Agent 對話`，打開 §3 的啟用流程。
- Agent 對話從「關閉」改成「開啟」時不直接開，先走 §3 的啟用流程。

### 刪除一種類型存下的資料

這是另外的動作，在「管理資料類型」每種類型的卡片上：`刪除「{名稱}」的存檔…`。它照 PME 先預覽、再確認：

- 標題 `刪除存檔裡所有的「{名稱}」？`
- `會從 PathKeep 的存檔刪掉 {數量}（{大小}），無法復原。`
- 下面逐項列出會刪掉的東西和各自的數量、大小：這個類型的每個資料庫、它的搜尋索引。
- Agent 對話多一句：`其中 {n} 段在工具自己的資料夾裡已經沒有了，刪掉就再也找不回來。`
- `刪除後這個類型會關閉。重新開啟之前，PathKeep 不會再備份它。`
- `工具與瀏覽器自己的資料夾不受影響。`
- 按鈕 `取消` / `刪除`

按下 `刪除` 後，這個類型的資料庫和搜尋索引從磁碟上刪掉，類型變成「關閉」。之後什麼都不會再備份進來，直到使用者重新開啟它；重新開啟時照 §3 的啟用流程，從工具或瀏覽器現在還有的資料重新存起。

這是 v0.6 把 Agent 對話從存檔移除的方法之一（另一個是刪除所有資料）。單獨一段對話只能移到垃圾桶，見 [agent-history.md](agent-history.md) §8。

## 3. 開啟一種類型：預覽 → 選擇 → 保存

開啟一種類型照 PathKeep 的 PME：先看會讀什麼，再自己選，最後才保存。PathKeep 不會自己開始掃描任何來源。

### 3.1 已經在用 PathKeep 的人

從 v0.5 升級上來時，Agent 對話是關閉的。

**介紹卡。** Agent 對話關閉、而且這台電腦上找得到至少一個工具的資料夾時，瀏覽紀錄的首頁有一張卡：

- 標題 `PathKeep 現在也能保存 Agent 對話`
- `這台電腦上有這些工具的資料夾：` 後面列出每一個找到資料夾的工具。
- `只看了資料夾在不在，還沒有讀任何內容。`
- 按鈕 `預覽會保存什麼`（打開啟用流程）/ `以後再說`，右上角一個 ×。

做這張卡只檢查資料夾在不在，不打開任何檔案。按 `以後再說` 或 × 之後，這張卡不會自己再出現。收起記在後端這台電腦的設定（`dismiss_agent_hint`），所以每個視窗、更新之後都一樣，另一台電腦照樣會出現；設定還沒回來之前不顯示，也不去找資料夾，不會閃一下。後端沒收下時，卡片回來，通知 `沒能關閉這張卡片`。

**其他入口**一直都在：切換選單最後一項 `保存其他類型的資料`、「設定 › 管理資料類型」把 Agent 對話切到「開啟」，以及 §2 的「沒有開啟」畫面。啟用流程是一個對話框，網址帶 `?enable=agent` 時打開。

### 3.2 啟用流程

對話框頂端是三步：`看會讀什麼` → `選擇` → `保存`。

**第一步：看會讀什麼**

- 標題 `保存 Agent 對話：先看看會讀什麼`
- `Claude Code 預設 30 天後刪掉舊對話，Codex 的紀錄也常被清掉。開啟後，PathKeep 把它們存進你的存檔，照專案、時間和全文都找得回來。`
- 一張表，每個找到的工具一列（從 §1 的那幾個裡面），欄位 `工具`、`資料夾`、`對話`（下面一行 `另有 {n} 個 subagent`）、`大小`、`最早`。數的是工具資料夾裡現在還有的檔案。
- `到這裡為止只數了檔案的數量、大小和日期，還沒有打開任何一段對話。`
- `會讀取`：
  - `對話紀錄檔，含 subagent 的紀錄`
  - `工具輸出和貼上的附件`
  - `專案資料夾的 .git：repo 的根目錄、worktree 屬於哪個 repo、目前分支、遠端網址`
- `不會做`：
  - `不寫入、不搬動、不刪除工具自己的資料夾`
  - `不啟動任何工具，不讀專案裡的程式碼`
  - `不傳到任何地方`
- 三個數字：`存檔預計多出 約 {大小}`（照存檔實際的存法估算）、`這顆磁碟還有 {大小}`、`加密 跟現在的存檔一樣`。
- 按鈕 `不用了` / `下一步`。`不用了` 關掉對話框，什麼都不改。

**第二步：選擇**

- 標題 `要保存哪些工具的對話？`，說明 `沒勾的工具不會被讀取。`
- 每個找到的工具一個勾選框，預設全勾，旁邊寫 `{n} 段 · {大小}`。
- 開關 `記下專案的 git 資訊`（預設開；PathKeep 讀 `.git` 是用戶 2026-11-13 同意的）：`worktree 刪掉以後就查不到它屬於哪個專案，所以要在備份當下記下來。只讀 .git 裡的 repo 的根目錄、worktree 屬於哪個 repo、目前分支、遠端網址，不讀程式碼。` 關掉時專案只照路徑歸類。
- 三行說明：
  - `排程跟瀏覽紀錄共用一個：{目前的排程}。`
  - `開啟後，左上角的切換選單會多一個「Agent 對話」（⌘{n} 也能切過去），切過去有洞察、紀錄、專案和它自己的備份頁。`
  - `之後可以在「設定 › Agent 對話」改這些選擇，或整個關掉；關掉不會刪掉已經存下的對話。`
- 按鈕 `上一步` / `開始保存 {n} 段`。一個工具都沒勾時 `開始保存` 不能按。

這一步的勾選和 git 開關就是「設定 › Agent 對話」裡的同一組設定，按下 `開始保存` 時存下。

**第三步：保存**

- 標題 `正在保存`，說明 `第一次要讀完全部的紀錄，之後只讀新增的部分。`
- 每個工具一條進度：`已保存 {a} / {b} 段`，完成後 `{n} 段都存好了`。
- `關掉這個對話框也會繼續存，進度在左下角的背景任務裡看得到。`
- 按鈕 `在背景繼續`：關掉對話框，通知 `在背景繼續保存` / `進度在左下角的背景任務裡看得到。`

規則：

- 按下 `開始保存` 的那一刻 Agent 對話就是「開啟」，切換選單裡就有它。
- 用任何方式關掉對話框（Esc、點外面、×、`在背景繼續`），保存都繼續，變成背景任務「備份 Agent 對話」。
- 第一次備份還沒跑完時，Agent 空間的每一頁都要能用，顯示目前已存下的部分，並說明第一次備份還在跑（每頁的寫法見 [agent-history.md](agent-history.md)）。

**完成**

- 標題 `存好了`，`保存了 {n} 段對話和 {m} 個 subagent，共 {大小}。`
- 按鈕 `關閉` / `看對話`。`看對話` 切到 Agent 空間的第一頁（洞察）。

**必須有的狀態：**

- 一個工具的資料夾都沒找到（從「管理資料類型」進來時會發生）。
- 某個工具的資料夾讀不到（沒有權限、磁碟沒接上）：那一列說明原因，其他工具照常。
- 預覽本身失敗。
- 保存時某個工具失敗：其他工具照常存完，失敗的那個在背景任務的「需要你看一下」裡。

### 3.3 第一次開 PathKeep（新手引導）

新手引導的步驟：`歡迎`、`要保存什麼`、`來源`、`存放位置`、`加密`、`自動備份`、`AI`、`完成`。步驟的名稱、按鈕（`繼續`、`上一步`、`跳過`）和下面沒提到的文字都照現在的 app。現在的每一步都留著，只有「瀏覽器」那一步換掉：先是 `要保存什麼`（選哪幾種類型），接著 `來源`（每一種選了的類型的來源）。拆成兩步是用戶 2026-11-13 同意的。

**歡迎**

- `留住會被自動刪掉的東西` / `瀏覽紀錄、跟 Agent 的對話，很多工具過一陣子就自己清掉了。PathKeep 定時把它們複製進你電腦上的存檔，之後隨時能找、能看。`
- 圖的標題改成 `各家自己會留多久`。現在的四列照舊（Chrome 與 Arc `約 90 天`、Safari `1 年`、Firefox `看容量`），加兩列：Claude Code `預設 30 天`、Codex `不自動刪，但常被手動清掉`；最後一列 PathKeep `永久` 照舊。
- 下面三點照現在的寫法（`只在本機`、`不碰原檔`、`可以搜尋`）。
- 這一步改的只有標題、說明、圖的標題和多出來的兩列，因為現在的文字只講瀏覽器。

**要保存什麼**

- `要保存什麼？` / `每一種之後都能在設定裡加減。關掉不會刪掉已經存下的資料。`
- 每種類型一張卡：名稱、為什麼要保存、來源。
- 預設勾的是這台電腦上找得到來源的類型（只看資料夾和歷史檔在不在，不讀內容；被系統擋住的 Safari 算找得到）。找不到來源的類型不勾，卡片上多一行 `這台電腦上沒有找到，所以先不選。之後找到了，首頁會問你要不要保存。`，使用者仍然可以自己勾。這樣沒裝任何 Agent 工具的人不會在下一步被擋住。
- 一種都找不到時預設勾瀏覽紀錄，下一步會說明找不到瀏覽器並提供 `重新檢查`，跟現在一樣。
- 一種都沒選時寫 `至少選一種。`，`繼續` 不能按。

**來源**

- `找到這些來源` / `PathKeep 只讀這些資料夾，不改、不刪任何檔案。不想備份的可以取消勾選。`
- 版面是左右兩欄，放在一張卡裡，卡片的高度跟著視窗，這一步本身不捲動。類型有八種、一種類型有幾十個來源時也是這個版面；只有兩種類型時，左欄就是摘要。只選了一種類型時沒有左欄，整張卡就是那一種的來源清單，跟現在的瀏覽器那一步一樣，多了 `全選`、`全不選`。
- **左欄**：選了的每種類型一列，點一列在右欄看它的來源，上下鍵可以換。每列寫：
  - 名稱；
  - `{n} {單位}，都備份`、`{n} {單位}，選了 {m} 個` 或 `{n} {單位}，一個都沒選`（單位：瀏覽紀錄是 `個設定檔`，Agent 對話是 `個工具`）；
  - 有來源要你處理時多一行 `{n} 個需要權限`；
  - 這個類型除了列出的資料夾還會讀別的東西時，寫在這裡：Agent 對話是 `也讀每個專案資料夾的 .git`。這樣沒點開那一種也看得到。
- **右欄**：選中那一種的來源。
  - 標題列：名稱、同一句摘要、`全選`、`全不選`；來源超過 8 個時多一個 `篩選` 輸入框。
  - 清單自己捲動。來源超過 8 個時依瀏覽器（或工具）分組，每組一列標題，有一個勾選框管整組，寫 `{選了幾個} / {共幾個}`。
  - 瀏覽紀錄這一種，現在瀏覽器那一步有的都留著，規則不變：
    - 只列有歷史檔的設定檔，加上被系統擋住的 Safari；沒裝的瀏覽器不列。
    - 每列：瀏覽器名稱、設定檔名稱、歷史檔的大小（滑鼠停在上面寫 `歷史檔案：{大小}`）。系統不讓讀的寫 `需要權限`、不寫大小、預設不勾，但可以先勾起來。
    - 一開始勾的是當下讀得到的每一個；上次沒做完的設定存過選擇的話，從那次的選擇開始。
    - Safari 的設定檔被 macOS 擋住、或 macOS 把全部都擋住（一個都列不出來）時，清單下方是現在的那則說明（只有 macOS 的 Safari 會這樣，Windows 和 Linux 上不出現）：`Safari 需要「完整磁碟取用權限」`、`打開設定`、`重新檢查`。打不開系統設定寫 `無法打開系統設定` 和原因，重新檢查失敗寫 `重新檢查失敗` 和原因；檢查當中按鈕不能按。
    - `重新檢查` 之後變成讀得到的設定檔不會自動勾上，要不要備份由使用者勾。
    - 一個都沒找到是 `找不到瀏覽器`，掃描失敗是 `PathKeep 無法掃描瀏覽器`，都帶 `重新檢查`。系統全擋住時只出現上面那則權限說明，不出現這兩則。
  - Agent 對話的列：工具名稱、讀的資料夾、`{n} 段對話`，下面一行 `另有 {n} 個 subagent · {大小}`。數的是工具資料夾裡現在還有的。清單下方兩則說明：
    - `備份時也會讀每個專案資料夾的 .git，只看 repo 的根目錄、worktree 屬於哪個 repo、目前分支、遠端網址，用來把同一個專案的資料夾併在一起。不讀程式碼。之後可以在 Agent 對話的備份頁關掉。`
    - 一個工具都沒找到（使用者在上一步自己勾了這個類型）：`找不到 Agent 對話的來源` / `PathKeep 會尋找 Claude Code、Codex、Pi、DeepSeek Harness 的資料夾。裝好並使用過之後，再檢查一次；或回上一步先不選這個類型，之後找到了，首頁會問你。`，帶 `重新檢查`。
    - 選了 Claude Code 時：`Claude Code 預設 30 天後刪掉舊對話（可以在它自己的設定裡改）。第一次備份會把現在還在的 {n} 段先存下來。` PathKeep 不讀工具的設定檔。
- 選了的每一種類型都要有一個勾起來、而且 PathKeep 讀得到的來源，才能按 `繼續`。這是現在「至少選一個 PathKeep 能讀取的瀏覽器」的規則，套到每一種類型：只勾了被系統擋住的設定檔不算，一個來源都沒找到的類型也不算。不符合時卡片下方寫 `「{類型}」沒有選到 PathKeep 能讀取的來源。選一個，或回上一步取消這個類型。`
- 按 `繼續` 時把選的類型和來源存下來；存的當中 `繼續` 不能按，存不了寫 `無法儲存你的選擇` 和原因，留在這一步。沒做完就關掉的話，下次照現在一樣從 `歡迎` 開始，但選過的類型、來源和備份間隔都還在。
- `完成` 那一步的摘要每種類型一列，寫選了幾個讀得到的來源；Agent 對話那一列後面加 `也讀每個專案資料夾的 .git`。

**存放位置**：照現在的寫法。現在那三個數字（來源現在的大小、第一次備份後大約的大小、來源的數量）改成每種選了的類型一列；選了兩種以上時加一列 `合計`。只選瀏覽紀錄時就是現在的三個數字。

**加密**：照現在的寫法，標題下加一句 `所有資料類型放在同一個存檔，這裡選的套用到全部。`「不加密」的說明加一句 `Agent 對話裡常有程式碼、金鑰和私人路徑，請想清楚。`

**自動備份**：照現在的寫法和選項，標題下加一句 `一個排程，所有資料類型一起備份。`

**AI**：照現在的寫法。

**完成**：標題與說明照現在的寫法。摘要列照現在的（`瀏覽器`、`存放位置`、`加密`、`自動備份`、`AI`、`連網`），最前面加一列 `保存`（選了哪幾種），`瀏覽器` 後面加一列 `Agent 工具`；每種類型那一列寫選了幾個來源。`連網` 那一列改成指到「設定 → 瀏覽紀錄」，因為開關搬過去了；沒選瀏覽紀錄時沒有這一列。按下開始後照現在一步一步做（每一步的狀態、重試、略過都照舊），只有「第一次備份」那一步每種選了的類型各一行進度，各是一個背景任務。結果也是每種類型各一行，用自己的單位（瀏覽紀錄 `新增 {n} 條記錄`，Agent 對話 `存了 {n} 段對話`），不加在一起；某一種沒備份完或失敗時，那一行寫原因並指到那個類型的備份頁，其他類型照常完成。

新手引導的外框照現在：左邊的步驟清單與能不能跳回去、收尾時鎖住、語言選單和深淺色（語言只是不放在主畫面的導航列，這裡的留著）、視窗的拖動區。

### 3.4 需要處理的事（提醒列）

現在只出現在首頁頂端的提醒，v0.6 起分兩種：

- **整個存檔的**：自動備份的問題（排程器回報的那幾種）、加密存檔的鑰匙圈不能用、密碼不在鑰匙圈、密碼只有使用者自己記得。它們出現在**每個空間的第一頁**頂端（瀏覽紀錄的首頁、Agent 對話的洞察），因為打開 PathKeep 會回到上次那個空間的第一頁，瀏覽紀錄也可能關著。內容、條件、按鈕和「我有妥善保管」之後不再提醒的規則都照現在。
- **只屬於一種類型的**：讀不到 Safari、找不到瀏覽器，只在瀏覽紀錄的首頁。Agent 對話自己的提醒見 [agent-history.md](agent-history.md)。

每則提醒連到修的地方：排程的問題到「設定 › 排程與背景工作」，密碼與鑰匙圈到「設定 › 安全」，來源的問題到那個空間的備份頁。

瀏覽紀錄首頁其他跟著空間改的只有這幾處：

- 右上的備份狀態膠囊和 `立即備份` 只講瀏覽紀錄、只備份瀏覽紀錄（§4）。別的類型備份失敗不會讓它變紅；那會出現在背景任務的「需要你看一下」。
- `存檔大小` 那張卡寫存檔裡瀏覽紀錄佔的大小，照舊連到「設定 › 儲存」，那裡每種類型一行。
- 來源卡上沒在備份的瀏覽器寫 `不備份`，不寫 `已暫停`（「暫停」現在是整個類型的狀態）。備份頁的來源列也一樣。

## 4. 每個空間自己的備份頁

每個空間的「備份」只管這個類型自己的來源（`#/browsing/backup`、`#/agent/backup`）。

### 三個地方各管什麼

備份有關的事分在三個地方，名稱在整個 app 裡都一樣：

| 地方                   | 管什麼                                    |
| ---------------------- | ----------------------------------------- |
| 備份頁（每個空間一個） | 這個類型存什麼、從哪裡存，和現在就備份它  |
| 設定 › 排程與背景工作  | PathKeep 什麼時候自己備份、背景工作怎麼跑 |
| 背景任務               | 現在在跑什麼、什麼在等、什麼需要你看一下  |

每個備份頁都有一列連到排程的設定；背景任務頁右上也有。排程放在設定裡、從每個備份頁都到得了，是用戶 2026-11-13 同意的。

### 備份頁

- **主要的事**：這個類型的資料安不安全；現在備份它。
- **預設顯示**：一行狀態加 `立即備份`、自動備份那一列、來源清單、需要注意的事。
- **收起來**：每個來源保存了哪些部分（點那一列展開）、最近的備份。

**標頭**

- `備份`，副標 `{名稱} · {數量}。只讀來源，不改也不刪。`
- 標籤 `上次備份：{時間}`。
- `立即備份` 只備份這個類型。按下後通知 `開始備份「{名稱}」` / `只備份這個類型。要全部一起備份，用左下角背景任務選單裡的「全部立即備份」。`
- 這個類型正在備份時，按鈕的位置換成 `正在備份 · {進度說明}` 和一條進度條。
- 同一種類型同時只有一個備份。它已經在備份時，這一頁的按鈕、`全部立即備份`、⌘K 的 `立即備份`、選單列和排程都不會再替它開第二個；`全部立即備份` 只開還沒在跑的那幾種。
- 備份結束時的通知照現在的寫法，每種類型各一則：完成（新增幾筆，或沒有新增）、沒備份完（原因，例如 Safari 沒有權限而略過）、失敗（原因）。從選單列或排程開始的備份，視窗開著時也一樣通知並更新畫面。
- 瀏覽紀錄首頁右上的 `立即備份` 跟這一頁的一樣，只備份瀏覽紀錄；首頁的備份狀態膠囊也只講瀏覽紀錄。
- 網址帶 `?run={id}` 時打開那一次的詳情，就算它不在這一頁的清單裡（別的類型的、很久以前的）。

**來源**卡（副標 `點一列看保存了哪些部分`）：每個來源一列，依序是圖示、名稱、（有的話）提醒標籤、數量、上次備份、狀態、展開箭頭。每列的 ⋯：

| 項目               | 做什麼                                                             |
| ------------------ | ------------------------------------------------------------------ |
| `在 Finder 顯示`   | 打開這個來源的資料夾                                               |
| `重新掃描這個來源` | 重新看一次這個來源的資料夾，更新找到了什麼和數量。它不備份任何東西 |

`在 Finder 顯示` 在 Windows 寫 `在檔案總管顯示`，Linux 寫 `在檔案管理員顯示`。

每個來源只有一個控制：它的開關，就在這一列上，兩個空間都一樣（瀏覽紀錄是現在每個設定檔的開關）。開著就備份；關著就不備份，已存的留著，狀態寫 `不備份`。來源沒有另外的「暫停」。

凡是決定「備份讀什麼」的都在這張來源卡上，不在設定裡：來源的開關、加入其他資料夾、匯入，以及 Agent 對話的 `備份時也讀專案資料夾的 .git`。

**最近的備份**（預設收起）：收起時一行摘要 `{時間} · 有 {n} 次沒有全部存下` 或 `都正常`。展開後每次備份一列：結果圖示、時間、`花了 {時長}`、這個類型在那次備份裡做了什麼、警告（沒存下來的）。只列這個類型的部分和這個類型的警告。Agent 對話另有備註（存下了、讀的時候遇到的情況），見 [agent-history.md](agent-history.md) §6。

整個存檔的工作（健康檢查、清理、改密碼或加密、從副本還原）也列在這裡，打開是瀏覽紀錄那邊的詳情。詳情的 `觸發方式` 每一種都用白話寫：`你手動觸發`（整個存檔的工作也是）、`排程器`、`PathKeep 在更新舊的紀錄時`、`透過 MCP 連線的應用程式`、`PathKeep 在建立存檔時`；舊版 PathKeep 留下、不在這幾種裡的寫 `沒有記下`，不把代碼直接印出來。

**自動備份那一列**在標頭下面，兩個空間的備份頁都一樣，內容永遠來自同一個排程狀態：

| 排程的狀態                                                                                             | 這一列寫                                         | 按鈕                                  |
| ------------------------------------------------------------------------------------------------------ | ------------------------------------------------ | ------------------------------------- |
| 開著、排程器正常                                                                                       | `{目前的排程} · 下次 {時間}`                     | `更改排程`                            |
| 關著                                                                                                   | `自動備份關著`                                   | `設定排程`                            |
| 排程器有問題（需要修復、需要授權、留著舊版的工作、排程檔跟設定不符、Linux 要手動設定、算不出下次時間） | 現在「自動備份」卡上對應的那句狀態，用警告的樣子 | `處理`（Linux 手動設定時是 `看步驟`） |
| 還在讀                                                                                                 | 骨架                                             | 沒有                                  |

按鈕都打開「設定 › 排程與背景工作」，修復、授權、移除舊工作和詳情都在那張卡上，這一列不重做一份。排程的問題仍然會出現在瀏覽紀錄首頁的提醒列，它的連結改成打開「設定 › 排程與背景工作」。

現在文字裡叫使用者「到備份」處理排程的幾句（刪除所有資料後排程沒移掉的說明、新手引導 `跳過` 的說明、逾期與沒備份完的排程說明）都改成指到「設定 › 排程與背景工作」，三種語言一起改。

**頁尾**：`存檔裡的{名稱}約 {大小}（來源 {大小}）。` 存檔裡的大小要讀存檔的檔案才算得出來，頁面先畫好，數字後到；還沒到時那個位置先放佔位，不讓那一行跳動。

**必須有的狀態：**

- 上一次備份失敗或沒備份完：標頭的狀態行說明，並指到「最近的備份」裡那一次。
- 來源讀不到（沒有權限、磁碟沒接上）：那一列的狀態寫原因。讀不到不等於檔案不見了。
- 來源的開關關著：那一列的狀態寫不會備份它，並連到它的開關。
- 這個類型暫停中：標頭說明不會照排程備份，`立即備份` 仍然可以按。
- 第一次備份還沒跑完。
- 一個來源都沒有。

瀏覽紀錄的備份頁這次不重做（[data-spaces-tradeoff.md](../design/data-spaces-tradeoff.md) §4.5），沿用現在的 Backup 頁（來源依瀏覽器分組、兩種匯入、最近的匯入、最近記錄與它的詳情），只改兩件事：現在的「自動備份」卡搬到「設定 › 排程與背景工作」，這一頁留下上面那一列 `自動備份`；`最近記錄` 列出跟瀏覽紀錄有關的備份與匯入，加上對整個存檔做的事（重新加密、健康檢查、還原、清理），只跟別的類型有關的不列。對整個存檔做的事在每個空間的備份頁都看得到，這樣現在查得到的記錄一筆都不會少。「自動備份」卡搬走後，兩張匯入卡並排一列，`最近的匯入` 自己佔一整列，不留空格。

### 一個排程，和「全部立即備份」

- 整個 PathKeep 只有一個排程，每次備份所有「開啟」的類型；「暫停」和「關閉」的不備份。排程在「設定 › 排程與背景工作」改（§8），可選的間隔照 [archive.md](archive.md) §0 與 [backup-interval-tradeoff.md](../design/backup-interval-tradeoff.md)。
- `全部立即備份` 備份所有「開啟」的類型。它在背景任務指示器的選單和背景任務頁上，不在切換選單裡。
- 選單列圖示的「立即備份」和排程一樣，備份所有「開啟」的類型。
- 人按下去的備份（`全部立即備份`、⌘K、選單列）略過了暫停的類型時，通知說略過了哪個、為什麼（`「{名稱}」暫停中，這次沒有備份它。`）；開著卻沒有選任何來源的也一樣說，附 `選擇來源`。關閉的類型不提。不會出現「什麼都沒備份」：一定至少有一種資料開著，開著的類型不是跑了、失敗了，就是沒有來源（這會說）。同一次按下只通知一次，後面的回覆沒有新消息就不再跳出來。
- 每種類型的備份是各自的背景任務。

## 5. 背景任務

### 5.1 導航列上的指示器

在導航列共用區的最上面，位置永遠不變。

| 狀態                           | 樣子                             |
| ------------------------------ | -------------------------------- |
| 有任務在跑，都知道總量         | 一個圓環，填到這些任務進度的平均 |
| 有任何一個在跑的任務不知道總量 | 一個轉圈的圓環                   |
| 沒有任務在跑                   | 一個安靜的圖示                   |
| 同時有兩項以上在跑             | 另外顯示數字，用中性的前景色     |
| 有任務需要你看一下             | 另外加一個小點                   |

- 無障礙名稱：`背景有 {n} 項任務在跑` / `背景任務：{n} 項需要你看一下` / `背景沒有在跑的任務`。
- 系統開了「減少動態效果」時圓環不轉。
- 滑過或鍵盤聚焦時，稍等一下（約 180 ms）打開一個小視窗；指標移到小視窗裡時不關。點一下到背景任務頁（`#/tasks`）。

小視窗：

- 標題 `背景任務`。
- 每個在跑的任務一列：名稱、`{n}%` 或 `準備中`、進度條（不知道總量時是不定進度）、一行說明。
- 沒有任務在跑時：`現在沒有在跑的任務。下次排程備份在 {時間}。` 沒有設排程時要有另一句。
- 底下兩行（有才顯示）：`還有 {n} 項在排隊`、`{n} 項需要你看一下`。
- 按鈕 `全部立即備份`、`打開背景任務`。

### 5.2 背景任務頁 `#/tasks`

- 標題 `背景任務`，副標 `{n} 項在跑，關掉視窗也會繼續。` 或 `現在沒有在跑的任務。` 「關掉視窗也會繼續」只在選單列圖示開著時寫（那時關視窗不會結束 PathKeep）；圖示關著時副標是 `{n} 項在跑。`，結束 PathKeep 前照現在的做法先問。
- 右上：`排程與背景工作`（打開那個設定頁）、`全部立即備份`。
- 現在放在設定裡的工作清單（佇列、最近的工作、進度、錯誤、重試與取消）是狀態，不是設定，都在這一頁（用戶 2026-10-15、2026-11-13）。

分組，照這個順序：

| 分組         | 什麼時候出現         | 每列的操作                                                         | 空的時候                        |
| ------------ | -------------------- | ------------------------------------------------------------------ | ------------------------------- |
| 需要你看一下 | 有失敗的任務時       | `再試一次`、`收起`                                                 | 不出現                          |
| 正在跑       | 一直都在             | 備份：`取消`。建立搜尋索引：`暫停`、`取消`。其他佇列的工作：`取消` | `沒有。下次排程備份在 {時間}。` |
| 等待中       | 有排隊或暫停的任務時 | 暫停的那些有 `繼續`、`取消`；排隊的有 `取消`                       | 不出現                          |
| 今天完成     | 一直都在             | 沒有                                                               | `今天還沒有做完的任務。`        |

每列：

- 開頭是這個任務屬於哪個空間：那個空間的圖示。不屬於任何一個空間的任務寫 `整個存檔`。
- 任務名稱；右邊在跑時是 `{n}%` 或 `準備中`，其他時候是時間。
- 在跑或暫停時有進度條。
- 一行 `{說明} · {附註}`。例如暫停的任務附註 `你暫停了`；失敗的任務附註原因（`檔案在備份時正被寫入，下次會再試`）。

四個分組下面是 `佇列與資料`，放現在「設定 › 背景工作」裡除了兩個設定以外的全部，內容、文字、每個按鈕和確認對話框都跟現在一樣：

- `洞察與網頁細節` 佇列：摘要、`重建`（先確認）、最近的工作。
- `搜尋索引與助理` 佇列：摘要、最近的工作；AI 關著時連到「設定 › AI」。
- 兩個佇列的最近工作先列五筆，`顯示全部` 之後可以一路往前讀到最早的一筆。
- `網頁摘要`：已摘要的數量、在跑／在等／失敗的數量、`立即抓取`；關著時連到「設定 › 瀏覽紀錄」的開關。
- `連結預覽`：有預覽圖的比例、`立即清理`（先確認，寫出保留圖片的規則）；關著時連到同一個地方。
- `洞察資料`：每一部分的版本、狀態、上次建立、為什麼過期，`清除…`（先預覽會刪幾筆、保留什麼；重建在跑時不能按）和清除後的 `立即重建`。
- `額外的網頁資訊`：每個外掛的筆數、上次執行、上次的錯誤。

這些都屬於瀏覽紀錄，開頭標著瀏覽紀錄的圖示；瀏覽紀錄關閉時不出現。「設定 › AI」語意索引旁邊的 `背景工作` 連結、以及其他指到工作清單的連結，都改成打開這一頁。

規則：

- `再試一次` 用同樣的範圍把同一個任務再跑一次（例如「備份 Agent 對話」就再備份一次 Agent 對話）。
- 「需要你看一下」的一列在重試成功或你按 `收起` 時消失。
- Agent 對話的備份碰到 PathKeep 還讀不懂的格式版本時，那次備份雖然成功，也列在「需要你看一下」，寫出是哪個工具的哪個版本、檔案已照原樣存下；每則提醒有自己的 `收起`，只收那一則（[agent-history.md](agent-history.md) §6）。同一次備份如果也有沒存下來的，它另有 `再試一次`、`收起`，收掉提醒後它還在。只有備註的備份不列進來。
- 剛記下、還沒開始的備份寫 `正在開始`，沒有按鈕，當作還在做。
- 備份可以取消，不能暫停。取消的備份留下已經存好的部分，下一次備份接著做剩下的。
- 索引與佇列的工作（搜尋索引、洞察、語意索引、網頁摘要、連結預覽）保留現在就有的操作，不多也不少：能暫停和繼續的只有建立搜尋索引；其他的是取消和重試（舊版助理留下的問題不能重試）。同一時間只送出一個操作，送出當中其他按鈕不能按。

任務的種類包括每種類型的備份（`備份 Agent 對話`、`備份瀏覽紀錄`）、啟用時的第一次保存、更新搜尋索引、重算洞察、語意索引、重新解析。每一種都回報進度，知道總量時給總量，而且可以取消（[agent-history-product-design.md](../architecture/agent-history-product-design.md) §9）。

## 7. 助理與 AI 能讀什麼

助理頁這次只多一樣東西：頂端的範圍那一列，和它帶來的幾個狀態。其他全部照現在的 app：對話清單（依日分組、改名、刪除、匯出、新對話與 ⌘N、往前翻頁）、回答的串流與停止、思考過程與搜尋次數、引用的頁面、複製與重試、編輯先前的問題、模型選擇、用量與上下文的提示、每次回答後自動存下、離開這一頁時停下並存下正在回答的那一則。

- 每段助理對話記著它自己的範圍，回到那段對話時範圍還是一樣。開新的對話時，範圍是使用者當下所在的空間，可以再加選其他類型。v0.6 之前存下的對話，範圍是瀏覽紀錄。
- 沒有可用的 AI 服務、或 AI 關著時，照現在的畫面（說明這是可選功能、連到「設定 › AI」、存下的對話照樣能讀），範圍那一列不能改。這個狀態優先於下面幾個。
- 助理不能讀「關閉」的類型，也不能讀 AI 開關關著的類型。
- 助理頁頂端是 `問的範圍：`，每種開著或暫停的類型一個標籤。能讀的打勾；不能讀的 Agent 對話是一個鎖，旁邊連結 `在設定裡允許`。
- Agent 對話不能讀、又只選了它時，頁面寫：
  - `助理還不能讀「Agent 對話」`
  - `Agent 對話裡常有程式碼、金鑰和私人路徑，所以預設不給助理讀。到「設定 › Agent 對話 › AI 存取」打開後才會用；或先在上面選別的類型來問。`
  - 按鈕 `到設定允許`
- 一個類型都沒選時：標題 `選一個類型來問`。
- 能問的時候：現在空對話的標題和說明照舊（含用的是本機模型還是線上服務、線上服務時會把需要的片段送出去的那句），前面加一句 `只會讀「{類型}」。` 輸入框 `問問你的{類型}…`；沒有能讀的類型時 `先選一個助理能讀的類型`。
- 範例問題：範圍含瀏覽紀錄時是現在的四個；只選了 Agent 對話時換成 Agent 對話的四個（文案在做那個畫面時寫，三種語言）。點一個就送出，跟現在一樣。
- 回答引用 Agent 對話時，引用的標籤寫對話的標題和工具，點了到 Agent 的「紀錄」並打開那段對話、捲到被引用的那一輪。引用瀏覽紀錄的照現在。
- 刪除一段助理對話照現在的確認；說明裡「不會影響你的瀏覽歷史」改成不只講瀏覽紀錄的說法。

讓 AI 讀 Agent 對話的開關有三個，各自分開，預設都關：助理、語意搜尋索引、MCP。內容見 [agent-history.md](agent-history.md) §7。瀏覽紀錄維持現在的做法。「設定 › AI」裡有一列 `各類型的資料能不能給 AI 讀` / `在各資料類型自己的設定裡分開開。`，下面是每種類型一個連結，寫出現在的狀態（例如 `Agent 對話：預設都關`）。

## 8. 設定

設定的左欄分兩組：

- `PathKeep`：`一般`、`安全`、`AI`、`排程與背景工作`、`儲存`、`關於`。
- `資料類型`：`管理資料類型`，接著每種開著或暫停的類型一項。只跟一種類型有關的設定，都放在「設定 › 資料類型 › 那一種」。

網址：`#/settings/background`（排程與背景工作，沿用現在「背景工作」的網址）、`#/settings/kinds`（管理資料類型）、`#/settings/agent`、`#/settings/browsing`。語言在「一般」裡，不在導航列（用戶 2026-11-13）。

**管理資料類型**

- 開頭：`每一種資料各自開關。暫停和關閉都不會刪任何東西：已存的留在存檔裡，重新開啟就回來。要刪掉已存的資料，是另外的動作。`
- 每種類型一張卡：圖示、名稱、為什麼要保存、`來源：…`、三段切換（§2）、`刪除「{名稱}」的存檔…`。

**排程與背景工作**（`#/settings/background`）只放設定，不放狀態：

1. `自動備份` 卡，照現在 Backup 頁上的那一張：間隔的選項、下次備份、上次自動備份、排程器的狀態、`詳情`。加一句 `一個排程備份所有「開啟」的類型。`
2. `背景工作` 分組，開頭的說明照現在的寫法：`執行背景工作`、`同時執行的工作數`。現在同一頁上連結預覽的兩個選項（`何時抓取`、`保留圖片`）只跟瀏覽紀錄有關，搬到「設定 › 瀏覽紀錄」，放在 `連結預覽` 的開關下面。PathKeep 沒有跟電源有關的設定。
3. 一列 `背景任務` / `正在跑、在排隊、今天做完或沒做完的任務。左下角的指示器也能打開。`，按鈕 `打開背景任務`。

**儲存**：`存檔大小` 每種類型一行；關閉的類型後面寫 `（沒有開啟，資料保留）`。

**安全**：開頭寫 `所有資料類型都在同一個存檔裡，用同一把密碼、同一次解鎖。` 存檔加密的那一列說明它套用到所有資料類型。

**哪些東西放在哪裡**（用戶 2026-11-13 同意）。照「你在哪裡會想改它」分：

| 地方                     | 放什麼                                                                     |
| ------------------------ | -------------------------------------------------------------------------- |
| 每個空間自己的備份頁     | 這個類型存什麼、從哪裡存：來源的開關、加入資料夾、權限、匯入、備份時讀什麼 |
| 設定 › 資料類型 › 那一種 | 跟備份無關、只屬於這一種、又同時影響好幾頁或影響空間以外的偏好             |
| 設定 › PathKeep 那一組   | 所有類型共用的：排程、加密、AI 服務、存檔、語言與外觀                      |

在設定裡替每種類型開一頁，是因為類型變多之後，「一般」和「儲存」會塞進只對某一種有意義的列。

**每種類型自己的設定**：Agent 對話的見 [agent-history.md](agent-history.md) §7。瀏覽紀錄的那一頁：

- 開頭一句話連到 `#/browsing/backup`：要備份哪些設定檔、匯入，都在那裡。
- `連網` 分組，說明照現在的寫法（`只有這兩項會連線到網站，其他一切都留在這台電腦上。`）：`連結預覽`（開著時下面是 `何時抓取` 和 `保留圖片` 兩個選項，現在在「背景工作 › 連結預覽」）、`連結預覽圖`（數量、大小、`清除…` 與它的確認對話框）、`頁面摘要`。前兩列和第三列現在在「一般 › 連網」，`連結預覽圖` 現在在「儲存」。
- `匯出` 分組：`匯出歷史`（格式選擇、`匯出…`、進度與 `停止`），現在在「儲存」。

每一列的內容、文字和行為都跟現在一樣，只換位置。別處連到這些開關的連結跟著改：「紀錄」頁上連結預覽關著時的 `去開啟`、背景任務頁上 `網頁摘要` 和 `連結預覽` 關著時的連結，都直接到「設定 › 瀏覽紀錄」。設定內容欄的寬度不變（680 px）。「一般」原本「連網」分組的位置留一列 `連網`，說明會連線到網站的只有瀏覽紀錄的這兩項，並連到「設定 › 瀏覽紀錄」；瀏覽紀錄沒開時不出現。

## 9. 加密

Agent 對話跟著存檔的加密選擇走（用戶 2026-11-13）。整個 PathKeep 只有一個存檔：一個加密選擇、一次鎖定、一次改密碼、一個復原流程、一個「刪除所有資料」。

- 存檔加密時，所有類型都加密；不加密時，所有類型都不加密。沒有「只加密某一種」。
- 鎖定時所有類型都看不到，助理和 MCP 也讀不到。
- 啟用流程的預覽寫 `加密 跟現在的存檔一樣`，不另外問。
- 怎麼做到見 [agent-history-product-design.md](../architecture/agent-history-product-design.md) §5。
