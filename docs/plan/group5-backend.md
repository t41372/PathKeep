## Released reader and fixtures

The release test unpacked `PathKeep_0.5.0_linux_amd64.deb`. Its SHA-256 matched the release checksum, `429234a1e42945474d8a1b4aebfd705c6b8078d906223e2e81eca3a7b2a07a2f`. It upgraded the released archive, backed up a new visit, prepared it for the previous version, and had v0.5.0 back up a second new visit. The checked-in encrypted data folder and the separate format-2 move file came from [the v0.5.0 fixture](../../tests/fixtures/v0.5-archive/README.md).

The released-binary test takes `PATHKEEP_TEST_V05_DESKTOP` and runs under Xvfb and a private D-Bus session. The filesystem test takes `PATHKEEP_TEST_FAT_VOLUME` and requires a writable mounted test volume. Both tests are explicitly selected with `--ignored` when those inputs are available.

From `src-tauri/`, the focused checks can be repeated with these commands.

```sh
cargo test --locked -p vault-worker --test vault_lifecycle group5::
cargo test --locked -p vault-worker --test vault_lifecycle move_to_empty_and_populated_destinations
cargo test --locked -p vault-worker --test root_admission
xvfb-run -a dbus-run-session -- cargo test --locked -p pathkeep-desktop --features devtools-bridge --test root_admission_startup dev_ipc_bridge_foreground_refusal
PATHKEEP_TEST_V05_DESKTOP=/path/to/released/pathkeep-desktop xvfb-run -a dbus-run-session -- cargo test --locked -p vault-worker --test vault_lifecycle released_binary_can_back_up_into_the_handoff -- --ignored
PATHKEEP_TEST_FAT_VOLUME=/mnt/test-volume cargo test --locked -p vault-core --test storage_volume -- --ignored
```

## Linux results and release gate

The focused run passed 17 lifecycle cases, with the released-binary case selected and passed separately. All 88 root admission cases passed. The actual foreground desktop returned the read-floor refusal over the bridge, rejected a wipe and left the root byte-for-byte unchanged. A separate closed-archive recovery-window run on the released fixture reported 1,952 visits before detach and 1,952 after rejoin. The backup-integrity E2E configurations passed 10 healthy-archive cases and one damaged-archive case. The released v0.5 UI project passed all three of its open, restore and move-file cases when run independently.

The primary Playwright run reported 128 passed, five failed, one skipped and 80 blocked by project dependencies. All five failures used the Claude Desktop folder count in `tests/e2e/support/agent-tools.ts`. The fixture contains a main Cowork transcript and its audit file. The adapter classifies the audit as metadata when the main transcript exists. The expectation counted both as conversation files. Rebuilding unmodified `ff4f6f1c`, completing onboarding and rerunning the first failing case produced the same expected count of two and actual count of one. The comparator desktop also rejected the Group 5-only `get_archive_access` command. [Preview expectation](../../tests/e2e/support/agent-tools.ts) · [Cowork discovery](../../src-tauri/crates/agent-history/src/adapters/claude/discovery.rs)

As a separate diagnostic, the blocked Agent Backup project was run on the retained fixture. Three cases passed and eight failed. Its first save timed out looking for the data-type switcher while the enable dialog was visible. Those results came from a resumed project and are recorded separately from the primary run. The UI session owns the preview expectation and the dependent screens.

The final `bun run check` passed the JavaScript checks, production frontend build, Rust workspace, desktop bridge and release configuration phases. The lifecycle binary reported 104 passed and one explicitly selected release test. The full command exited with status 1 at the five preview assertions above. The two existing source-approval tests were also run against the final importer. Keeping a conversation preserves its evidence. Continuing to read a tool folder still requires the approval checks against the original move file.

The dedicated boxd machine was `pathkeep-group5` (`b67f4612-1d31-47d3-8e51-a4d6c8217b01`). It was restarted once after a failed machine state. The raw logs, Playwright JSON and failure traces were retrieved before deletion. Metered cost reported after deletion was **US$1.543735**.
