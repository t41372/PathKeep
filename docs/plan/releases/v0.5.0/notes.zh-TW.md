# PathKeep v0.5.0

發布預演草稿，尚未發布。另一個 worktree 的 embedding 修復整合後，必須重新驗證並重建所有安裝包，才能提交最終發布審閱。

PathKeep v0.5.0 改善瀏覽器備份，加入搜尋排序與搜尋建構器，並在建立新的語意索引時繼續提供現有索引。AI 仍然可選。

## 升級之前

新版會自動升級存檔與語意索引的中繼資料。**v0.4.0 無法開啟升級後的資料，也無法匯入新版匯出的可攜式存檔。** 如果要保留降回 v0.4.0 的能力，請在升級前完全退出 PathKeep，保存整份資料目錄的副本，並保留存檔密碼。這是降級相容性的限制，不是升級已知會失敗。

升級後第一次備份會重新讀取已選瀏覽器的歷史。大型存檔需要較久，Insights 也可能在背景重建。瀏覽器已經刪除的歷史，無法再從該瀏覽器救回。

## 這次改變

- 備份以網址與瀏覽器自己的時間識別造訪，瀏覽器重新使用列號時，不再因此悄悄漏掉新造訪。升級會保留導覽連結；Firefox Sync 副本各自保存，但只計算一次。
- 執行結果區分完整、部分完成與失敗，並列出各個設定檔的結果。選單列與排程會保留最近一次備份的警告，直到之後的備份解決它。
- 備份回覆後，連結預覽繼續在背景取得。
- History 可以排序搜尋結果，也可以用介面組合文字與模式搜尋。完整加上引號的運算子會當作文字，模式搜尋的後續頁面延續同一次搜尋。
- 語意索引按完整的代發布；新索引完成前，搜尋繼續使用現有完整索引。History 說明這次搜尋實際使用哪個索引。關閉語意搜尋後，不再送出 embedding 請求。
- 匯入、匯出等受保護工作還在進行時，退出會先詢問如何處理。前一次儲存尚未完成時，新編輯的筆記與標籤仍會保留。
- Insights 在新結果發布後重新讀取，跨瀏覽器與搜尋引擎的相同搜尋只列一次。Ask 會說明模型沒有寫出回答就結束的情形。

## 已知限制

- 14.4M 次造訪時，部分 Insights 卡片第一次讀取，以及沒有精確結果的搜尋，可能要一分鐘以上。大型存檔變更網站類別也很慢。
- 後來才找到的開啟者會立即更新 Navigation，但已建好的 Insights 路徑要等完整重建。
- 目前沒有單獨清除語意索引檔案的介面，大型索引可能佔用很多磁碟空間。
- 刪除所有資料前請先停止備份；刪除不會等待正在跑的備份。
- 備份開著的瀏覽器時，取得可讀副本可能需要等待，也可能出現讀取副本的備註／警告。

## 下載與安裝

提供 Apple Silicon／Intel Mac、Windows x64 與 Linux x64 套件。Windows 安裝程式維持未簽章的 preview，Linux 套件也維持 preview。Safari 在 macOS 需要「完整磁碟取用權」。Firefox 仍限歷史紀錄；Atlas 與 Comet 仍限已驗證的 macOS 歷史設定檔。

這些 preview 套件未簽章，須手動安裝，不提供 app 內自動更新。macOS 可能阻擋下載的 app，更新後也可能需要重新授予完整磁碟取用權。Windows 可能顯示「未知的發行者」或 SmartScreen 提示。

下載後請依 `SHA256SUMS.txt` 與 `RELEASE-MANIFEST.json` 核對檔案。這些 preview 套件不附更新簽章或 `latest.json`。JavaScript 鎖檔稽核結果為零。Rust 稽核通過，保留八項有紀錄的例外。
