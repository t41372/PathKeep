## Faults and fixtures

- [ ] `tests/capture_crash.rs` exits the child inside the progress callback at `raw_committed` and `projection_published`. `tests/reparse_source.rs` cancels at `projection_staged`. Preserve the three boundaries and payload fields in capture and reparse. The owner lifecycle fixtures under `vault-worker/tests/vault_lifecycle/conversations/{corpus,ownership}.rs` collect revision IDs at raw commit and block an active producer during maintenance.
- [ ] `tests/projection_integrity.rs` uses the public staging API to inject duplicate ordinals, superseded attempts, raw-head changes, partial coverage and retired generations. `query_export`, `archive_integrity`, `export_stream`, `lineage_ambiguity`, `search_integrity` and `verification` also construct projections independently of their raw bytes. Supply actual native fixtures before removing this seam. Keep process-death recovery for unfinished chunks.
- [ ] `archive/damage_tests.rs` deletes a manifest row, sets a session revision to a nonexistent ID, constrains the mark mirror, and pins a garbage slice by foreign key. Preserve typed damage, recoverable marks and retryable collection. The retained-window test also damages a compressed stored slice.
- [ ] `archive/membership_tests.rs` clones session rows by enumerating columns to create 600 copies. `archive/read_concurrency_tests.rs` holds the publication lock during a list read. Preserve bounded SQL parameters and independent reads.
- [ ] `search/state_tests.rs::after_filter` changes trash visibility mid-query. `search/sync/tests.rs` inspects the real engine plan for ordinal seeks without a sorter. `tests/search_integrity.rs` cancels a partial drain and damages a segment with intact commit metadata. Replace each probe at the equivalent publication or seek boundary.
- [ ] `tests/{line_export,export_stream}.rs` publish from inside an output writer, including same-byte reparse and inherited-source replacement. Keep the failure on mixed interpretations, output errors and byte-exact raw export.
- [ ] Run `tests/cli_e2e.rs`, the native scale verifier, and owner lifecycle tests against both archive modes. Preserve the CLI's physical records and raw digest oracle independently of new product grouping.

For the final sweep search the **whole repository** for `ah_(events|sessions|event_references|reference_outcomes|attachment_counts|attachment_generations|projection_gaps|lineage_validation|coverage|projection_work|projection_retired|outbox|meta|user_state|state_generation)`, the three progress phase strings, and `prepare_projection|append_projection|publish_projection`. Check SQL generated from table names, EXPLAIN probes and tests under the owner crates as well as literal SQL. The standalone README and research implementation notes describe the old projection.
