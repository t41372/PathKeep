# 上一頁 / 下一頁與 Windows、Linux 的視窗按鈕 — Trade-off

> **狀態：Accepted — 用戶 2026-10-12 選定 D（上一頁 / 下一頁放導航列；Windows、Linux 的視窗按鈕畫在底層右上角）**
> **範圍：** 導航列頂端、主面板的上邊距、Windows 與 Linux 的視窗外框
> **牽涉的已接受文檔：** [screens-and-nav.md](screens-and-nav.md) §導航（「沒有上一頁 / 下一頁按鈕」與導航列頂端、拖動區那段）

## 1. 為什麼要改

- 用戶要全域的上一頁 / 下一頁（2026-10-12）。現在只有洞察的 drill-in 有「← 洞察」，其他地方回不去，只能再點一次導航列。
- 視窗是兩層：底層是視窗背景，導航列與 macOS 的紅綠燈在上面；主面板是浮在上面的圓角面板。Windows 與 Linux 卻是系統標題列加上這兩層，看起來像別的 app 套了我們的內容，導航列頂端放的品牌標誌也只在那兩個平台出現。

## 2. 選項

**A. 上一頁 / 下一頁放主面板左上角（Finder / Safari）。** 主面板左上角是各畫面自己的東西（History 的搜尋列、Ask 與 Settings 的側欄），每個畫面都要讓位。

**B. 整個視窗頂端加一條 top bar，放上一頁 / 下一頁、搜尋與視窗按鈕。** 用戶看過後放棄：History 的搜尋搬到 bar 上不對勁，多一條 bar 也破壞兩層的設計。

**C. 只有快捷鍵與選單。** 看不到也想不到。

**D. 上一頁 / 下一頁放導航列；Windows、Linux 的視窗按鈕畫在底層右上角（用戶選的）。**

```
macOS                                    Windows / Linux
● ● ●                                                                  ─  ☐  ✕
 ‹ ›   ┌ 主面板 ──────────────────┐       ‹ ›   ┌ 主面板 ──────────────────┐
 🏠    │                           │       🏠    │                           │
 🕘    │                           │       🕘    │                           │
```

- **上一頁 / 下一頁**：導航列頂端、五個主畫面上面，兩個並排的小箭頭（macOS 在紅綠燈下面）。沒有上一頁時變灰。走 router 的歷史：篩選與選取用 `replace`，不進歷史，所以只會在畫面與 drill-in 之間跳。快捷鍵 ⌘[ / ⌘]（Windows、Linux 用 Alt+← / Alt+→）與滑鼠側鍵，在文字框裡不攔。
- **Windows、Linux 的外框**：不用系統標題列（`decorations: false`）。主面板的上邊距加大，露出一條底層，最小化 / 最大化（還原）/ 關閉畫在這條的右上角，跟 macOS 紅綠燈在左上角是同一個位置關係。這條空白處可以拖動，雙擊最大化 / 還原。導航列頂端的品牌標誌拿掉，三個平台的導航列一樣。
- **Windows 11 的貼齊版面（snap layouts）**：滑鼠停在最大化上要出現。用微軟的 `windows` crate 在 Rust 裡回應 `WM_NCHITTEST`，讓系統把那個按鈕當成最大化按鈕，不另加依賴。無邊框視窗的邊緣縮放、Aero Snap 拖到螢幕邊緣也要照舊能用。
- **macOS** 不變，只在紅綠燈下面多了上一頁 / 下一頁。

## 3. 怎麼比

- **一致**：D 讓三個平台都是同樣的兩層，按鈕在每個畫面同一個位置，不用每個畫面各自讓位；A 每個新畫面都要記得讓位。
- **空間**：Windows 上少一條系統標題列（約 30 px），主面板上邊距多出的那條比它窄，內容反而多。
- **風險**：自己畫的視窗按鈕要做到跟系統一樣好：最大化與還原的圖示切換、深淺色、關閉 hover 的紅色、鍵盤與輔助技術、snap layouts。做不到就比系統的差，所以這些都要在 Windows 實機確認，不能只看截圖。Linux 各桌面環境的按鈕不一樣，我們畫的是同一套，跟 macOS 紅綠燈一樣是 app 自己的樣子。

## 4. 決定

用戶選 D（2026-10-12）。`screens-and-nav.md` §導航改成：導航列頂端有上一頁 / 下一頁；Windows、Linux 不用系統標題列，視窗按鈕在底層右上角。
