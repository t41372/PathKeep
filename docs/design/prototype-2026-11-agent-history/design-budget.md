# 每個畫面的預算（第 3 輪）

第 2 輪的問題是「什麼都畫上去」：一列對話最多十個元素、閱讀器標頭三排加橫幅、洞察五個 KPI 加十二張卡。這份預算規定每個畫面只有一件主要的事、預設只顯示什麼、什麼收在一次點擊後面。東西是**移走**不是刪掉：token 和時間是用戶要的，只是不放在每一列。

判斷依據（Apple 設計基礎）：每個畫面一眼答得出「我在哪、能做什麼、下一步去哪」；頂層目的地 3–5 個；大量內容按時間或使用者自己的分組，不平鋪；強調色少量用在可點的東西和選取狀態，不鋪大面積。

## 外框

- 導航列 = 空間切換鈕 ＋ 目前空間的 4 個頁面 ＋ 分隔線 ＋ 共用的「助理」「設定」＋ 背景任務指示器與三個小工具（⌘K、鎖定、主題）。語言不在導航列。
- Agent 空間：洞察（第一頁）、紀錄、專案、備份。瀏覽紀錄空間：首頁、紀錄、洞察、備份。
- Agent 頁面隨視窗寬度伸展，不放在置中的固定寬度欄裡；多出來的寬度要放有用的東西（更多欄位、更多卡片欄），不留大片空白。
- 空間只用圖示＋名稱＋淡淡的底色區分；顏色永遠不是唯一的線索。
- 切換鈕的選單：每個空間一行狀態、加入其他類型。「全部立即備份」與背景任務放一起（左下角指示器的選單、背景任務頁）。

## 對話（清單）

- 主要的事：找到並打開一段對話。
- 預設：搜尋框、一個「篩選」按鈕（有作用中的條件時顯示數字）、作用中的條件才以可移除的小標籤出現。
- 每列只有：標題、時間；工具 icon、專案名稱；有星號或「只剩這裡有」才多一個小圖示。
- 收起來：排序與分組（在篩選選單裡）、每段的 token / 時間 / subagent / 分支 / PR（在閱讀器的資訊面板）、日期標題上的統計、底部合計、沒選對話時的統計格。
- 例外：照 token 或時間排序時，那個數字才出現在列的右側。
- 日期（或專案）分隔：從左邊到右邊的淡色橫條，上下各一條細線，上面多留一點空，右側寫「N 段」。列是圓角、內縮的，分隔用列沒有的樣子，快速捲動時一眼找得到。捲動時目前這一天的橫條釘在頂端，底下的列會被模糊掉；那一天自己的橫條還在原位時不釘（所以清單最上面只有一條），下一天的橫條到頂時把它推上去，像 macOS 的清單標題。

## 閱讀器

- 主要的事：讀這段對話、接著做。
- 標頭一排標題、一排說明（工具 icon＋名稱 · 專案 · 日期 · Agent 時間）。
- 按鈕：「繼續」、「資訊」、⋯（匯出、所有事件、在這段對話裡找、目錄、改名、在 Finder 顯示、複製連結）、關閉。
- 橫幅只留「只剩 PathKeep 有」一種，一行。worktree 已刪寫在「繼續」選單和資訊面板裡。
- 內容：每組工具呼叫一行（有改檔才顯示 +/−）；思考一行；subagent 一張小卡；每輪結尾的時間與 token 只在滑過那一輪時出現。
- 資訊面板預設關；打開時先顯示「時間與 Token」「在哪裡做的」，其餘分段收起。

## 專案（目錄）

- 主要的事：到某個專案的對話；把在意的專案照自己的方式排好。
- 「預設」看法：上面「釘選」卡是使用者的區塊（可巢狀、可收合、可拖曳排序，也能用「移到…」選單；「＋區塊」和 ⋯ 在這張卡的標題列），下面「其他專案」卡有自己的搜尋與篩選，按最近活動排，先顯示 15 個。
- 每列：圖示、名稱＋位置（同名專案靠位置分辨）、工具、對話數、最近活動、⋯（專案的所有操作）。
- 「清單」「資料夾」兩種看法還在；token、Agent 時間這類欄位只出現在「清單」，可排序。
- 一個專案可以有好幾個資料夾；可能屬於同一專案的資料夾是「其他專案」頂端的一行提示，不講「合併」。
- 名稱和資料夾在「專案設定」裡改（每列的 ⋯、點進專案後的標頭按鈕）。不叫「資料夾」：那聽起來像「打開這個專案的資料夾」，那是「在 Finder 顯示」（用戶，2026-11-13）。
- 區塊是使用者的資料：新專案進「其他專案」；區塊刪掉，裡面的專案回到「其他專案」，不刪任何東西；資料夾不在了，專案留在原位、圖示變灰；把資料夾加進別的專案時，那個專案保持原位置。

## 點進一個專案

- 主要的事：看這個專案的對話。
- 就是「對話」的清單＋閱讀器，只列這個專案。標頭：名稱、路徑（一行、淡色）、「洞察」按鈕、「專案設定」按鈕、⋯（和專案頁每列的 ⋯ 同一份選單）。

## 洞察

- 洞察是給人看的報告，不是拿來操作的工具（用戶，2026-11-13）：像儀表板一樣全部攤開，不折疊，密一點沒關係。
- 它是 Agent 空間的第一頁。
- 標題旁用灰字寫目前的範圍（「洞察（最近 30 天）」），免得以為數字是全部的。第一次打開是全部時間；選過的範圍會記住，下次打開還是同一個。工具與專案篩選不記：回來看到一份被悄悄篩過的報告會誤導（用戶，2026-11-13）。
- 順序：五個數字（Agent 工作時間、你在場的時間、Token、費用、對話）→ 一年（日曆、這一年的數字）→ 時間與依專案 → Token → 什麼時候（作息、你在場、各工具）→ 做了什麼（最久的對話、改動、工具、模型）→ 花了多少（費用、這些數字怎麼算）。越有用的越上面；排版不准為了填空改這個順序（用戶，2026-11-13）。
- 一年日曆是唯一的例外，放在數字列下面：它是唯一不受時間範圍影響的卡片，而且寬度固定，放進卡片牆中間或最後都會把上面幾欄切出空洞。日曆卡片只有日曆那麼寬，右邊的「這一年」卡片（總時數、有對話的日子、每天平均、最長連續、最忙的一天和月份、每月長條）補滿這一列，放不下時換到下一列。
- 其餘卡片是一面依高度堆疊的牆：欄數隨寬度變，卡片上緣永遠照上面的順序由上往下，不做 dense 回填。作息的格子跟一年日曆一樣大（13px），一欄放得下。
- 時間的用語統一寫在 `src/data/labels.ts`：「Agent 工作時間」按時鐘算，同時開幾個都只算一次；「分開加總」每段各算各的。例子直接寫在卡片上。按天算的數字（一年日曆、首頁的這一週）在午夜切開：跑過午夜的對話兩天各算各的那一段，所以一天不會超過 24 小時。

## 備份（每個空間各一份）

- 主要的事：這個空間的資料安不安全；現在備份它。
- 預設：一行狀態＋「立即備份」（只備份這個空間）、來源清單（每個來源一列：icon、名稱、數量、上次備份、狀態）、需要注意的事（例如 Claude Code 會自動刪舊對話）。
- 收起來：每個來源保存了哪些部分（展開該列）、歷次備份紀錄、排程（只寫一行「所有類型共用一個排程 · 在設定裡改」）。
