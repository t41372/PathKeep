# 原型：v0.6 多種資料類型與 Agent 對話（2026-11）

用 app 自己的元件、設計 token、字型與圖表（`src/components/ui`、`src/components/app`、evilcharts、Streamdown、`@tanstack/react-virtual`）畫的可操作原型。資料全是用固定種子生成的假資料，規模照一台真實機器的數量（只數過數量）：約 300 個專案、1,900 多段主對話、上萬個 subagent，部分對話沒有用量或時長紀錄。

這不是 app 的一部分：不進 build、不接後端，只用來在動手實作前把產品設計定下來。

它是暫時的。畫面做進正式前端（`src/`）之後，這個資料夾連同 `.prettierignore` 與 `eslint.config.js` 裡的排除項一起刪掉，不會進 `main`。設計決定以 `docs/` 裡的文件為準，不以這裡的程式或這份說明為準。

## 怎麼開

在 worktree 根目錄：

```sh
./node_modules/.bin/vite --config docs/design/prototype-2026-11-agent-history/vite.config.ts
```

然後打開 <http://127.0.0.1:1431/>。右下角「原型選項」可以切換：

- 導航：**切換空間**（第 3 輪，預設）或 **依類型**（第 2 輪），兩種並排比較；
- 開了幾種資料類型（只有 Agent／只有瀏覽／兩種／六種）、升級後還沒開 Agent、背景有沒有任務在跑、深色、玻璃材質；
- 直接跳到幾個特殊狀態（最長的對話、只剩 PathKeep 有的對話、已刪除 worktree 裡的對話、點進一個專案、可能同一專案的資料夾、背景任務、首次開啟流程、新手引導）。

型別檢查：`./node_modules/.bin/tsc -p docs/design/prototype-2026-11-agent-history/tsconfig.json --noEmit`。

每個畫面預設顯示什麼、收起什麼，寫在 [design-budget.md](design-budget.md)。

## 兩種導航

**切換空間（第 3 輪）**：每種資料類型是一個空間，像切換 profile。導航列頂端是切換鈕（目前空間的圖示＋名稱），下面固定是這個空間自己的頁面，視窗底色與強調色跟著空間換。

- Agent：洞察（第一頁）／紀錄／專案／備份；瀏覽紀錄：首頁／紀錄／洞察／備份。兩邊都叫「紀錄」，跟內建的「助理」（聊天機器人）分開。
- 共用（分隔線下）：背景任務指示器（最上面）、助理、⌘K、鎖定、主題、設定。切換鈕下方的小圓點表示目前是第幾個空間，呼應左右平移。
- 切換：點切換鈕、⌘1…⌘9（Windows、Linux 是 Ctrl+1…9）、⌘K「切換到」。從別的空間的連結或搜尋結果跳過去，會自動切換。
- 切換鈕的選單只放空間：每個空間一行狀態，加上「保存其他類型的資料」。「全部立即備份」和背景任務放在一起（左下角指示器的選單、背景任務頁）。
- 每個空間的「備份」頁只管自己的來源，「立即備份」只備份這個空間；排程仍是全部共用一個。

**依類型（第 2 輪）**：每種類型一個導航項，頁面在面板頂端的分頁；只開一種時頁面直接放進導航列。

我對「切換空間」的評估（不是全盤同意）：

- 好處：頁面永遠在導航列同一個位置，不會一下在左邊、一下跑到頂端；類型再多也只是選單多幾行；每個空間的備份頁只看自己，邏輯清楚；底色一眼看出在哪。
- 代價與處理：
  - 「現在在哪個空間」是隱藏狀態 → 切換鈕永遠寫著名稱，不只靠顏色。玻璃材質下桌面透出來，底色會很淡，這時幾乎只剩切換鈕。
  - 跨空間的事要有固定的家 → ⌘K 搜全部空間、背景任務與整個存檔狀態放共用位置、助理預設看目前空間但可以加選其他空間。
  - 不叫「profile」：瀏覽紀錄的來源裡已經有 Chrome 的「個人／工作」profile，會撞名。介面上只寫類型名稱。
  - 每個空間一個強調色，推翻了已接受文件「只有一個品牌色」，要寫取捨文件。按工具分的圖表改用固定的工具色，不跟空間的強調色走。
  - Agent 空間沒有「首頁」，第一頁是洞察（用戶 2026-11-13 決定）。

## 版面寬度

Agent 的頁面（洞察、專案、專案洞察、備份）不再放在置中的固定寬度欄裡，而是從導航列旁邊開始、隨視窗變寬（`src/components/fluid-page.tsx`）：

- 洞察：數字列下面是一年日曆（只有日曆那麼寬）和「這一年」卡片（補滿這一列）；其餘卡片是一面依高度堆疊的牆，筆電兩欄、1600 寬三欄、2560 寬五欄，卡片上緣照 `design-budget.md` 的順序由上往下，不留空洞。
- 專案表在寬螢幕（約 1500px 以上）每列多顯示「最近的對話」，名稱和數字之間不會空一大段。
- 閱讀器的內文仍限制行寬，方便閱讀。
- 瀏覽紀錄的頁面暫時維持原樣，之後再一起改。

## 畫進去的設計決定（待確認）

- **工具用自己的官方圖示**（來源見 `src/assets/harness-icons/README.md`），不用縮寫。
- **漸進揭露（操作用的畫面）**：對話列只剩標題、時間、工具圖示、專案；篩選與排序收進一個「篩選」按鈕；閱讀器標頭一排標題一排說明，其餘在「⋯」與「資訊」；每輪的時間與 token 滑過才出現；連續派出的 subagent 收成一行。
- **洞察例外**：它是給人看的報告，全部攤開像儀表板，不折疊。
- **時間有兩個數字**：「Agent 工作時間」按時鐘算，同時開幾個都只算一次（兩個一起跑 1 小時算 1 小時）；「分開加總」每段各算各的（同樣情況算 2 小時）。比值是平均同時開幾個。另有估算的「你在場的時間」。用語集中在 `src/data/labels.ts`。
- **Token 一定拆開顯示**：輸出、輸入、寫入快取、讀取快取；沒紀錄的不算成 0。
- **費用按 API 牌價**：工具記下的照用，其餘按 PathKeep 附的牌價表估算（`src/data/pricing.ts`，價格為虛構），本機模型不估；可在洞察或設定裡關掉估算。
- **搜尋**：`/` 搜全部對話（或這個專案），⌘F 在打開的對話裡找。
- **背景任務**：導航列左下固定一個指示器：有任務時是會填滿的圓環（不知道總量時轉圈）加數字，滑過列出在跑的任務，點了進背景任務頁；沒任務時是安靜的圖示，位置不變。語言切換從導航列拿掉（在設定裡）。
- **專案頁**（第 4 輪重做）：跟其他頁一樣的標題與卡片，三種看法共用一套欄位（名稱＋位置、工具、對話、最近活動、⋯），日期一律寫「今天／3 天前／2 個月前」。
  - 「預設」看法：上面是**釘選**（自己的區塊，可巢狀、收合、拖曳排序；「＋區塊」和 ⋯ 在這張卡的標題列），下面是**其他專案**，有自己的搜尋、工具篩選、活動篩選與排序，找到後直接拖進釘選。
  - 一個專案可以有好幾個資料夾：在「專案設定」裡「加入資料夾…」「移出」，不講「合併」。可能屬於同一專案的資料夾在「其他專案」頂端一行提示。
  - 「專案設定」放名稱和資料夾。原本這個選單項目叫「資料夾…」，用戶覺得像「打開資料夾」，也想不到要去那裡設定（2026-11-13）。
  - 每個專案的 ⋯（或右鍵）：打開對話、洞察、改名、釘選、移到區塊、專案設定…、在 Finder 顯示；專案的對話頁標頭用同一份選單，另有「專案設定」按鈕。
  - 同名專案靠位置分辨（`~/code/api`、`~/work/acme/api`）。
  - 「資料夾」看法預設收合，單一子資料夾的路徑會合併成一行。
  - 區塊規則：新專案進「其他專案」；刪區塊不刪專案；資料夾不在了的專案留在原位、圖示變灰。拖曳用 pointer 事件、不加新依賴（也不用 HTML5 拖放，Tauri 視窗預設開著檔案拖放，可能衝突；沒實測）。
- **切換空間的動畫**：導航列裡屬於空間的項目（切換鈕、四個頁面）照切換方向左右平移並淡入淡出，項目間稍微錯開；共用項目不動。導航列先動，下一個空間的頁面等舊項目滑出後才渲染並淡入，所以重的頁面不會卡住動畫；動畫用 transform 與 opacity，交給合成器跑。減少動態效果時只淡入淡出。
- **類型的開關不刪資料**；**AI 讀 Agent 對話**各自一個開關，預設關。

## 和 app 現況不同的地方

- 這裡讓 Tailwind 掃了 Streamdown 的 dist，程式碼區塊與表格用 Streamdown 自己的外框。app 沒掃（只有 `src/features/ask/markdown.tsx` 一行註解，沒有文件說過不掃），Ask 用自己寫的排版。要在 app 裡用，只要在 `src/index.css` 加一行 `@source`；語法上色另外評估體積。
- 只畫了繁體中文。導航列標籤與篩選在英文、簡體中文下的寬度還沒驗過。

## 核心庫要補的（實作前）

一段對話的讀取模型（subagent 掛在父對話下、鏡像去重、分支、壓縮）；專案歸併（git root、worktree、遠端、搬家）與備份時記下 `.git` 資訊；使用者的專案區塊要存進存檔；每輪時間與 token 的來源與去重規則（每個工具不同）、時段聯集；全文搜尋改成串流、不設上限、片語相鄰、正規表示式、角色範圍；閱讀器的分段讀取與跳到第幾筆；每個空間各自觸發備份、背景任務的進度事件；存檔大小（現在約是來源的 2.9 倍）。

- 工具呼叫一組只寫「用了 N 次工具 · 改了 +x −y 行」，細目點開才看；失敗只留一個小點。

- 篩選把「排序」「分組」分開，工具多一個「全部」。

- 導航列在共用的項目上方加一條分隔線；背景任務的數字改成中性色，有失敗時多一個小點。
- 「全部立即備份」從切換選單搬到背景任務；切換選單的「加密中」改成「已加密」。
- 備份頁在這個空間正在備份時顯示進度，Claude Code 的提醒可以收起，不再三處重複。
- 瀏覽紀錄首頁拿掉三張狀態卡，摘要寫在標題下；「立即備份」改成次要按鈕。
