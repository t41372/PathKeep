# Backup page and backup schedule: feature parity

Audit of 2026-11-13. It starts from today's app and asks, for each thing a user can do, see or be stopped by, where the redesign has it.

- **Real app:** `src/features/backup/`, `src/components/app/backup-button.tsx` and `src/app/backup-runner.tsx`, plus what they import that users see. Modified files were read from `HEAD`. The E2E specs listed in the brief were also read. In the table, a bare real file name (`sources-card.tsx`) is under `src/features/backup/`; other paths are under `src/`, and E2E specs are under `tests/e2e/`.
- **Redesign:** `docs/features/data-spaces.md` §4, §5 and §8; `docs/design/data-spaces-tradeoff.md` §4.2 and §5; and the prototype. Prototype paths are relative to `docs/design/prototype-2026-11-agent-history/src/` (P = `pages/`).
- **Verdicts:**
  - `same`: the prototype has the feature and it behaves the same way.
  - `moved`: it is somewhere else.
  - `changed`: it is there in a different form.
  - `missing`: the prototype does not have it.
- **Covered** means the item is drawn in the prototype, is on a `parity/*.json` list with a reason, or is changed by a spec line that names it. A page the prototype marks `NotRedrawn` also counts, because the marker says "做進 app 時以現在的頁面為準，一項都不少" (only #116 relies on this). A doc that keeps the feature in words does not cover it when the prototype lacks it and no list names it. The real frontend will be built from the prototype, so those rows are UNDECIDED, with the doc line quoted.

## Needs a decision

Most user-visible first.

1. **#10 Backup failure toast.** A failed backup says nothing in the prototype. A user would not see the "備份失敗" toast or its explanation: Safari skipped for lack of Full Disk Access, no profile selected (`backup-no-profiles`), or the backend error. `check.ts` cannot see the `backup-no-profiles` sentence because the key has a hyphen.
2. **#112 Scheduler problem on the Backup page.** The new `自動備份` row only says on or off. A user on the Backup page would no longer see "排程器需要處理" with `修復`, or that Linux needs manual setup. The Home alerts that still report scheduler issues link to `/backup`, where the card no longer is.
3. **#47 Import that survives leaving the page.** In the prototype an import lives in the page. A user who leaves Backup during a long import would lose its progress, its `停止` and its finished result. `archive.md` §3 keeps this in words ("離開 Backup 再回來，進度與「停止」都還在"), and `import-stop.spec.ts` asserts it.
4. **#114 ⌘K `立即備份`.** The prototype palette has no action group, so the backup action is gone. `data-spaces.md` §6 keeps it in words ("`操作`（`立即備份`…）").
5. **#7 Toast for a backup that finished cleanly.** A user would get no "備份完成，新增 N 條記錄" or "沒有新增造訪". The prototype only draws the warning toast.
6. **#9 Toast for a partial backup that added nothing.** The "備份未完成，未新增造訪" title is not drawn.
7. **#22 Label for a switched-off source.** Spec §4 says it reads `不備份`. The prototype keeps today's `已暫停`, and `changed-on-purpose.browsing-backup.json` is empty. A builder would not know which label to ship.
8. **#4 Two backups at once.** Today only one manual backup runs at a time, and a second request is ignored everywhere. The spec splits backups per type but never says what this page's `立即備份`, `全部立即備份` or ⌘K `立即備份` does while another backup runs. `archive.md` §3 wants a second write action to join the running task.
9. **#14 Opening a run that is not in the list.** Today `?run=` opens any run. In the prototype it opens only runs in the filtered list. A link to a run of another type, an older run, or an old `#/backup?run=` link would open nothing.
10. **#117 Scope of `立即備份` on Home.** Home's button shares today's component. The prototype makes it back up only browsing history, but no spec line says so for Home.
11. **#11 Backup started from the menu bar.** Today it shows the same toasts in the window and refreshes the pages. The spec only says the menu bar backs up every type that is on.
12. **#115 Quitting during a backup, an import, or an import undo.** Today PathKeep asks first and names the work. The prototype has no quit question, and the spec is silent.
13. **#76 Run details that fail to load.** Today the sheet shows the error. In the prototype the detail always loads. There is no message key, so the string check missed it.
14. **#90 Automatic backup card before the status arrives.** Today it shows a skeleton. The prototype card always has data.
15. **#24 Source switch while a save is in flight.** Today the switch is disabled. The prototype never disables it.
16. **#93 Next run time.** Today a stale estimate moves forward by whole wake intervals as time passes. The prototype shows the backend's timestamp as it is.
17. **#48 Import busy guard and refresh.** Today a second inspect or confirm while one is running is ignored, the next file can be inspected while pages refresh, and a refresh that fails does not mark a finished import as failed (`import-runs.test.tsx`). The prototype has no refresh, so none of this is shown.
18. **#82 Names of profiles that are gone.** Run sentences name a profile that is no longer on this computer from source stats. The prototype falls back to the raw ID.
19. **#81 Entries recorded before codes existed.** Today they show first, and a sentence that also has a coded copy is not repeated. The prototype has no such step.
